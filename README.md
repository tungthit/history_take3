# Chill Geo-Flight

An interactive 3D globe explorer (React + three.js): countries, cities, landmarks, a History layer
(66 countries) and a Science layer (143 milestones across math, CS, physics, chemistry, biology and
medicine, with a time player, per-milestone stories and computed illustrations).

Extracted from the EnglishGami project (`frontend/src/games/geoflight/`). All UI text is English.

Entry component: `GeoFlight.jsx` (engine in `engine.js`, styles in `geoflight.css`).
It imports `../catalog.js` from the host app (see `GeoFlight.jsx`).
